# Part 2 — Formatting (COMPLETE)

## Fully working
- **Bold** on selection → wraps `**text**` (toggle off if already wrapped)
- **Italic** → `*text*`
- **Underline** → `__text__`
- **Strikethrough** → `~~text~~`
- Collapsed cursor: inserts markers, caret between them
- Alignment: left / center / right / justify on the editor field
- Bullet / numbered list styles
- Text color / highlight on selection (existing markers)
- Font size / family (editor style + document settings)
- Changes mark document dirty + history

## How to test
1. Type text, select a word, tap **B** → see `**word**`
2. Select again, tap **B** → markers removed
3. Alignment buttons change text alignment
4. Save, reopen — markers still in content
