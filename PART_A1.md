# Phase A1 — Real table editor

## Features
- Type inside each cell
- Row+ / Row− at selected row
- Col+ / Col− at selected column
- Clear cell
- Column width slider (0.5–2.5)
- Header row styled
- Markup: [TABLE] ... [/TABLE] with optional [W] widths
- Cursor inside existing table → Insert Table opens **Edit** and replaces block

## Test
1. More → Table → fill cells → Insert
2. Put cursor inside [TABLE] block → More → Table → edit → Update
3. Save and reopen — table markup preserved
