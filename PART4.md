# Part 4 — Document settings (COMPLETE)

## Settings (More → Document settings)
- Language (en/az/ru/ar)
- Page size: A3, A4, A5, Letter, Legal
- Landscape toggle
- Margins: Narrow / Normal / Wide
- Font family + size + line spacing
- Page numbers on/off + position
- Header text
- Footer text
- Auto-save on/off (8s debounce when on)

## Persistence
- Settings saved with document in LocalDocsCache
- Reopen document → settings restored
- Save button includes settings map

## Auto-save
- Triggers after edits when enabled
- Quiet local save
